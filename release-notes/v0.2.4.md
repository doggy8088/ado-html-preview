## Azure DevOps HTML Preview v0.2.4 — 自適應版面＋hover 複製圖示，文件換然一新

### ✨ 新功能

- **依內容結構自動調整版面**：Markdown 預覽會先讀懂文件的形狀再決定呈現方式，文字內容、順序與標題錨點完全不動。
  - 無標題的長篇文字（逐字稿等）改用 760px 以內的窄版閱讀欄，放大字級與行距。
  - 含寬表格的文件自動放寬內容欄（1320px），表格在卡片內自己水平捲動（7 欄以上的表格本來就有此行為，現在 6 欄的也會）。
  - 多章節參考文件採較緊湊的字級。
  - CJK 文件自動加大行距與字距。
- **標題裝飾**：
  - `主標 — 副標` 的 H1 自動拆成兩行，副標以較淡的層級呈現。
  - `2.1 標題` 的章節編號變成主色圓角徽章。
  - H2 依主題加上 Emoji 圖示（摘要 📌、疑難 🩺、待確認 ☑️、效能 ⚡、學習 📚 等約 20 類關鍵字），標題本身已有 Emoji 則不加。
  - 標題下方顯示「⏱ 約 N 分鐘閱讀 · N,NNN 字」。
- **清單自動卡片化**：
  - 每項都是「標籤：內容」的清單變成兩欄屬性表（含粗體鍵 `**標籤**：內容`）。
  - 3–8 個短而扁平的項目變成卡片；編號清單保留步驟圓牌（1、2、3…）。
  - 粗體開頭的長編號重點變成編號面板（左側主色線＋大號數字）。
- **表格互動**（依列數／欄數自動啟用，合併儲存格、多層表頭與巢狀表格不套用）：
  - **排序**：點欄名切換遞增／遞減／還原原始順序，欄名旁顯示 ▲▼ 方向。
  - **篩選**：12 列以上的表格附搜尋框與「顯示 n / t 列」計數。
  - **調整欄寬**：拖曳欄邊或用左右方向鍵（3 欄以上），雙擊還原單欄寬。
  - **還原順序與欄寬**：一鍵回到原始狀態。
  - **固定表頭**：維持既有設計，捲動時表頭吸在頂端（寬表格於卡片內捲動時除外）。
  - **橫捲提示**：寬表格可水平捲動時顯示「← 可左右捲動 →」，並可用鍵盤聚焦捲動（無障礙 region）。
  - **窄螢幕堆疊卡片**：長文字表格（≤ 4 欄）在窄容器變成堆疊卡片，欄名顯示在每格上方。
  - 排序與還原會以螢幕閱讀器可聽見的狀態播報。
- **狀態徽章**：表格儲存格開頭的 ✅ ⚠️ ❌ ※ 變成對應顏色的圓角徽章（綠／黃／紅／灰，深淺色皆適用）。
- **程式碼區塊右上角的複製圖示**：滑過程式碼區塊時淡入的雙方塊複製圖示，點一下複製整段程式碼；複製成功變綠色勾號（約 1.6 秒）。觸控裝置維持半透明常駐。功能不變（sandbox 內自動退回 `execCommand` 備援）。

### 🔄 行為變更

- 原本標示「複製」兩字的文字按鈕改為純圖示按鈕；保留鍵盤操作（Tab 聚焦現身、Enter 可複製）與螢幕閱讀器標籤。
- 表格欄名在可排序時變為按鈕（文字不變），欄邊多了可聚焦的調整握把；列印時所有控制項隱藏、被篩選的列照常顯示。
- 各項裝飾都在文件載入後由內嵌腳本加上：停用 JavaScript 時維持原本的靜態版面。

### ⚠️ 已知限制

- Emoji 圖示與徽章是視覺裝飾，不改變也不驗證內容的查證／狀態語意。
- 合併儲存格、多層表頭、多個 tbody 或巢狀表格只有捲動與徽章，不套用排序、篩選與欄寬控制。
- 複製的內容是程式碼區塊的純文字；Mermaid 圖表區塊不提供複製圖示。
- 其餘限制與 v0.2.3 相同。
