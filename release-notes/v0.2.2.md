## Azure DevOps HTML Preview v0.2.2 — 開啟檔案就自動顯示完整預覽

### ✨ 新功能

- **開啟支援的檔案時自動啟用「完整預覽 (內嵌)」**：
  在 Azure Repos 打開 `.html` / `.htm` / `.md` / `.markdown` 檔案（或切換到另一個這類檔案、切換分支）時，
  不用再按按鈕，內嵌預覽會自動顯示；目前不在 Preview 頁籤時會自動切過去，HTML 與 Markdown 都適用。
- 兩顆按鈕維持不變，隨時可以重開預覽或改用「全螢幕」模式。

### 🔄 行為變更

- 自動預覽**每個檔案（含分支）只觸發一次**：
  手動切回 Contents 等頁籤後不會被強行拉回 Preview；Azure DevOps 重建預覽區塊而讓預覽消失時也不會自動重開，
  這兩種情況按一下「完整預覽 (內嵌)」即可。
- 網址的 `_a` 參數指向 History / Blame / Commit / Diff 等頁籤時不會自動預覽（不搶走焦點）；
  `_a` 為 `contents`、`preview` 或沒有 `_a` 時視為「打開檔案」，照樣自動顯示。
- 版本選擇器還沒載入、分支尚未確定時不會提前自動預覽（避免抓錯分支的檔案）；確定後才顯示。
- 自動預覽失敗（例如抓檔錯誤）只會在瀏覽器 console 留下警告、不會自動重試，可用按鈕手動再試。
- PR、commit 資訊等 `/_git/{repo}/` 之後還有路徑段的頁面不再出現預覽按鈕：
  這些頁面即使網址帶 `path=` 也沒有可取代的預覽區塊，先前的按鈕在那裡無法運作。

### ⚠️ 已知限制

- 自動預覽會把 Azure DevOps 的預覽區塊換成我們的 sandbox iframe（與手動按按鈕完全相同的機制），
  想看 Azure DevOps 原生的靜態預覽時，請切到 Contents 頁籤或暫時停用擴充功能。
- 其餘限制與 v0.2.1 相同。
