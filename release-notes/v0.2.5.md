## Azure DevOps HTML Preview v0.2.5 — 新增 Makefile 開發指令

### ✨ 新功能

- **`Makefile` 常用開發指令**：新增一組列在 `make help` 的指令，方便在本機執行常見工作：
  - `make build`：打包 Chrome Web Store 上架 zip（即 `scripts/package.sh`，輸出於 `dist/`）。
  - `make userscript`：把 md 模組同步到 Tampermonkey 版（即 `node scripts/build-userscript.mjs`，
    可用 `USERSCRIPT=<路徑>` 指定目標檔案）。
  - `make lint`：語法與靜態檢查——所有 JS 檔 `node --check`、`scripts/package.sh` 的
    `bash -n`、manifest 與 `_locales` 的 JSON 驗證，以及商店描述（appDesc）132 字元上限檢查。
  - `make install`：檢查必要工具（node / jq / zip）；第三方函式庫已內建於 `vendor/`，無需安裝。
  - `make clean`：移除 `dist/` 建置產物。

### 🔄 行為變更

- 無。這是開發工具的新增，擴充功能本身（按鈕、預覽、換頁、主題）行為完全不變。

### 📦 同捆內容

### ⚠️ 已知限制

- 專案目前沒有測試套件與 formatter，`make test` 與 `make fmt` 只會印出提示訊息，
  不會執行任何測試或格式化；最接近的驗證是 `make lint` 與 `make build`。
- 其餘限制與 v0.2.4 相同。
