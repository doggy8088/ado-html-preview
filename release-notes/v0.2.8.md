## Azure DevOps HTML Preview v0.2.8（未單獨發布，併入 v0.2.9 一起發布）— 修正 PDF 預覽的掛載點

本版是 v0.2.7「新增 PDF 預覽」的實測修正，與 v0.2.7、v0.2.9 一起發布。

### 🐛 修正

- **修正「PDF 預覽 (內嵌)」找不到掛載區塊的問題**：在真實的 Azure DevOps PDF 檔案頁實測後發現，
  PDF 檔案頁**沒有 Preview 頁籤**（只有 Contents / History / Compare / Blame），
  也沒有 Markdown 用的 `.markdown-preview-container` / `.files-hub-content-preview`——
  檔案內容區實際是頁籤列（`.bolt-tabbar`）的兄弟節點 `div.page-content`。
  內嵌預覽現在直接取代這個內容區顯示，實測可在檔案頁內正常顯示 Chrome 內建的 PDF 檢視器。

### ✨ 完整功能（自 v0.2.7 併入）

請見 [release-notes/v0.2.7.md](v0.2.7.md)：PDF 預覽 (內嵌 / 全螢幕)、Git LFS 支援、
Chrome 內建 PDF 檢視器（搜尋、縮圖、列印、表單）、不引入 PDF.js、
以及 PDF iframe 不加 `sandbox` 的安全例外說明。

### ⚠️ 已知限制

與 v0.2.7 所列相同：就地換頁不含 `.pdf`；PDF 內嵌 JavaScript 不執行；
全螢幕視窗內容依賴來源分頁存活；超大 PDF 受 API 回應上限限制。
