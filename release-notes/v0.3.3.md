## Azure DevOps HTML Preview v0.3.3 — 新增 PowerPoint（.pptx）預覽、修正 Excel 大表看不到工作表頁籤

> 本版合併了未單獨發布的 v0.3.2（PowerPoint 預覽）與 v0.3.3（Excel / 深色模式修正）。

### ✨ 新功能

- **PowerPoint 預覽 (內嵌)：在 Azure DevOps 檔案頁裡直接看簡報**：
  打開 `.pptx` 檔案時自動顯示，內嵌掛自製的「Preview」頁籤（Contents / History / Compare / Blame 可正常切換），
  與 PDF / Excel / Word 預覽一致。
- **PowerPoint 預覽 (全螢幕)**：開新視窗全螢幕預覽同一份簡報。
- **高保真還原**：圖形（含預設幾何）、文字樣式、圖片、表格、圖表、SmartArt、群組、背景與漸層皆依原稿
  （渲染引擎 [@aiden0z/pptx-renderer](https://github.com/aiden0z/pptx-renderer) 1.4.0，Apache-2.0）。
- **好讀好找**：投影片由上而下依序排列、下方標示張數；隱藏投影片照常顯示並註明「隱藏投影片」。
  頂欄有目前張數（例如 `12 / 55`）與上一張／下一張按鈕，鍵盤 ← / → / PageUp / PageDown 換張、Home / End 到頭尾。
- **大型簡報按需載入**：圖片用到才解壓縮、投影片捲到附近才解析與掛載。實測 24 MB、55 張的簡報，
  在 Azure DevOps 內從抓檔到第一張顯示約 12 秒（含下載），之後捲動按需載入。
- **配色採紙張語意**（與 Excel / Word 預覽一致）：投影片顏色跟著「檔案」、不隨深淺色主題改變；
  只有頂欄與投影片之間的底色跟隨主題。

### 🔒 安全設計

- **自帶渲染器**：渲染引擎以原始碼字串打包（`pptx-runtime.js`），**只在 sandbox 預覽文件內執行**——
  Azure DevOps 頁面與 Tampermonkey 版都不執行它，渲染不可信簡報的程式與 Azure DevOps 完全隔離。
- 解壓縮套用資源上限（防解壓縮炸彈）、封鎖簡報內的外部媒體連結（預覽不對外連線）、不載入 PDF.js。

### 🐛 修正

- **Excel 預覽：資料量大的活頁簿看不到工作表頁籤**：
  工作表內容很多時（例如上萬個儲存格），頂欄下方的工作表頁籤列被擠成 0 高，
  頂欄雖然顯示「3 個工作表」，卻沒有地方可以切換。現在頁籤列固定保留高度，不論表格多大都能切換工作表。
  資料量小的活頁簿原本就正常，不受影響。
- **深色模式下 Excel 頁籤列變成白底**：頁籤列與頁籤文字現在跟著深淺色主題切換。
- **深色模式下頂欄統計文字太暗**：Excel 的「N 個工作表 · N 個儲存格」與 Word 頂欄的統計文字、載入狀態，
  在深色模式改用主題的次要文字色，不再是深灰字配深色底。
- 渲染引擎上游的預設圖形 bug：圓角矩形等圖形的弧度參數超過規格上限時（PowerPoint 會自動夾住），
  原本會畫成交叉弧線；現依 ECMA-376 規格夾值，膠囊形按鈕等設計可正確顯示。

### 🔁 行為變更

- 淺色模式的外觀與先前完全相同；表格本身（儲存格與欄列標頭）維持紙張語意，配色跟著檔案、不隨主題改變。

### ⚠️ 已知限制

- 僅支援 `.pptx`（舊版 `.ppt`、`.ppsx` / `.potx` 不支援）。
- 瀏覽器無法解碼的 TIFF 圖片以淺灰虛線框標示「無法顯示的圖片格式」。
- EMF / WMF 向量圖只在檔案內含點陣預覽時顯示，否則為空白。
- 不播放動畫、轉場、影片與音訊；以靜態投影片呈現。
- 簡報指定的字型未安裝時以系統近似字型呈現。
- 全螢幕模式受 10 MB 暫存上限限制，大型簡報（含大量圖片）請用內嵌預覽（內嵌模式無此限）。
- Tampermonkey 版因內嵌渲染引擎，檔案大小增加約 2.4 MB。
