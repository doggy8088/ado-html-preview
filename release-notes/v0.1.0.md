## Azure DevOps HTML Preview v0.1.0 — 首次發布

Azure DevOps 內建的 Preview 會把 HTML 放進受 CSP 限制的 iframe，檔案裡的 `<script>` 都不會執行。
這個擴充功能透過 Git REST API 取得原始檔，放進**隔離的 sandbox** 重新渲染：網頁腳本可以執行，但碰不到 Azure DevOps 的 cookie 或 session。

### ✨ 功能

- **完整預覽 (內嵌)**：直接取代 Preview 頁籤裡的預覽區塊，以啟用 JavaScript 的方式顯示網頁。
  - 若目前在 Contents / History 等頁籤，會自動切到 Preview。
  - iframe 高度填滿頁籤列以下的視窗，網頁在 iframe 內自行捲動，視窗縮放時自動調整。
- **完整預覽 (全螢幕)**：開一個與目前 Chrome 視窗同位置、同尺寸的獨立視窗，在擴充功能自己的 sandbox 頁面中渲染。
  - 這個模式的 CSP 允許 `eval` / `new Function`，需要它們的函式庫（例如 PDF.js）請用這個模式。
- **相對路徑資源內嵌**：預覽前會透過 Git Items API 把同 repo 的相對路徑資源抓回來內嵌，讓多檔案網頁也能正常顯示：
  - `<script src="…">` → 內嵌 `<script>`
  - `<link rel="stylesheet" href="…">` → 內嵌 `<style>`
  - `<img src="…">` → `data:` URL（以二進位格式抓取，圖片不會損毀）
- **連結修正**：
  - `#錨點` 在預覽內正常跳轉。
  - 相對路徑（例如 `../docs/x.md`）會在新分頁開啟 repo 內對應的檔案；HTML 檔會直接開在 Preview 頁籤。
  - 外部網址在新分頁開啟。
- **支援分支、tag、commit**：網址上的 `version=GB…` / `GT…` / `GC…` 會一併帶入，預覽的是你目前正在看的版本。
- **支援兩種網址格式**：`/{org}/{project}/_git/{repo}` 與省略專案段的 `/{org}/_git/{repo}`。
- 只在 `.html` / `.htm` 檔案頁顯示按鈕；Azure DevOps 是 SPA，切換檔案時按鈕會自動出現或移除。
- 按鈕會顯示「載入中…」，失敗時顯示錯誤原因，可直接再按一次重試。

### 🔒 安全與隱私

- 內嵌 iframe 與 sandbox 頁都**不含** `allow-same-origin`：網頁腳本跑在 null origin，無法讀取 Azure DevOps 的 cookie、localStorage，也不能呼叫 API。
- 內容腳本只注入 `https://dev.azure.com/*`，只向同一個 Azure DevOps 組織的 Git Items API 讀取你正在看的檔案與它引用的相對資源。
- 只要求 `storage` 權限：全螢幕模式用 `chrome.storage.session` 暫存 HTML，交給預覽視窗後立即刪除。
- 不收集、不傳送任何資料到第三方，沒有分析、沒有遠端伺服器。詳見 [隱私權政策](https://github.com/doggy8088/ado-html-preview/blob/main/docs/PRIVACY_POLICY.md)。

### ⚠️ 已知限制

- 腳本在執行期才 `fetch` 的檔案（例如 PDF.js 的 worker 與 `.pdf`）以及 CSS 內的 `url()` 不會內嵌，相對路徑會載不到。
- 每頁最多內嵌 60 個資源，單檔上限 8 MB；超過或抓取失敗的資源保留原樣（標上 `data-inline-failed`），不影響其他資源。
- HTML 若自己寫了 `<base href>`，會尊重作者設定，不做相對路徑內嵌。
- 內嵌模式繼承 Azure DevOps 的 CSP（沒有 `unsafe-eval`），用到 `eval` / `new Function` 的函式庫請改用全螢幕模式。
- 目前只支援 `dev.azure.com`，尚未支援 `*.visualstudio.com` 舊網域與 Azure DevOps Server（地端）。
- 介面文字目前只有繁體中文；擴充功能名稱與描述提供英文與繁體中文。

### 📦 安裝

- Chrome Web Store：審查中，通過後補上連結。
- 手動安裝：下載下方的 `ado-html-preview-0.1.0.zip` 並解壓縮，到 `chrome://extensions` 開啟「開發人員模式」→「載入未封裝項目」→ 選擇解壓縮後的資料夾。
- 需要 Chrome 112 以上版本。
