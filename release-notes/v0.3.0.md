## Azure DevOps HTML Preview v0.3.0 — Excel 與 Word 預覽：檔案格式大擴充

這是 minor 版本：自 v0.2.9 以來新增兩大檔案格式與一整套視覺品質框架，
v0.2.10–v0.2.12（未單獨發布）併入本版一起發布。

### ✨ Excel（.xlsx）預覽：主題化的唯讀表格

- **Excel 預覽 (內嵌 / 全螢幕)**：以 SheetJS 解析工作簿，自家主題的唯讀表格呈現——
  多工作表頁籤、儲存格基本樣式（粗體／斜體／底線／刪除線／字色／底色／對齊／自動換行／字級）、
  數字格式（日期、百分比、千分位）、合併儲存格、欄寬、列高、凍結窗格、Excel 風格欄字母與列號標頭。
- 樣式還原技術：SheetJS 只帶填色，其餘樣式自 `wb.Styles` 配合直接掃描工作表 XML 的每格樣式索引還原；
  佈景主題色依檔案內建色盤解析。支援 Git LFS。

### ✨ Word（.docx）預覽：高保真「自帶渲染器」

- **Word 預覽 (內嵌 / 全螢幕)**：docx-preview 0.4.1（Apache-2.0）＋JSZip 3.10.1（MIT）高保真渲染——
  字型樣式、表格框線與底色、對齊、頁首頁尾、圖片、分頁與頁面尺寸依原稿。
- **安全設計**：渲染引擎以原始碼字串打包，**只在 sandbox 預覽文件內執行**——
  渲染不可信文件的程式與 Azure DevOps 頁面完全隔離；內容 base64 內嵌、圖片 data URL、
  `</script>` 一律跳脫。

### 🎨 紙張語意：配色跟著「檔案」，不跟著主題

- Excel 表格與 Word 文件的內容配色完全還原原稿（Excel 裡是什麼顏色就顯示什麼顏色），
  深色模式下也一樣；只有頂欄外殼跟隨深淺色主題。
- 修正早期版本深色模式「未指定字色吃主題白字 × 檔案淺色底」不可讀的問題。

### 🔍 視覺驗證框架（寫入 AGENTS.md 的開發規範）

- 深、淺雙主題都要親眼看到成品才算通過；對比量測在**文字 run 層**（WCAG 4.5:1／大字 3:1）；
  紙張語意不變性（深／淺建置內容樣式必須一致）與對比檢查成為 `make test` 的硬性斷言
  （xlsx + docx 共 52 項）；來源檔案本身的低對比如實還原並註明，存疑時解剖來源檔 XML 對照。
- 截圖工具失效（快取／權限）時不得拿產出當證據，改以 computed style 與檔案層級證據並明說缺口。

### 🧰 其他

- 三種二進位格式（PDF / xlsx / docx）共用自製「Preview」頁籤機制（ADO 的這些檔案頁沒有
  Preview 頁籤）：預覽不寄生在 Contents 下，History / Compare / Blame 正常切換。
- `make test` / `make lint` 完整化；Tampermonkey 版同步（`@version` 0.3.0）。

### ⚠️ 已知限制

- xlsx：僅 `.xlsx`；不支援圖片、圖表、樞紐分析、篩選（公式顯示快取值）；單表超過 60,000 格截斷提示。
- docx：僅 `.docx`（舊 `.doc` 不支援）；追蹤修訂以合併結果顯示；註解不顯示；字型未內嵌時用系統近似字型。
- 全螢幕模式受 10 MB 暫存上限限制（內嵌無此限）；其餘限制與 v0.2.9 相同。
