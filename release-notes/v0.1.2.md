## Azure DevOps HTML Preview v0.1.2 — 新增 Markdown 預覽

### ✨ 新功能：Markdown 預覽

開啟 repo 內的 `.md` / `.markdown` 檔案時，頁籤列右側的按鈕會變成 **Markdown 預覽 (內嵌)** 與 **Markdown 預覽 (全螢幕)**，
以擴充功能自己的排版主題取代 Azure DevOps 內建的 Markdown 預覽。重點在「好讀」：

- **為中英混排設計的排版**：系統字型堆疊（PingFang / Noto Sans TC / Segoe UI），內文 16px、行高 1.75，標題字級與上下留白有明確節奏，文章置中、欄寬約 820px，不會一行拉到螢幕盡頭。
- **深淺色主題**：初始模式跟著 Azure DevOps 目前的主題（深色介面就是深色預覽），預覽右上角可隨時切換；兩套配色都經過對比檢查，程式碼上色在深色下也清楚。
- **側邊目錄**：由標題自動產生，捲動時高亮目前段落，可用頂欄按鈕收合；也支援文內 `[[_TOC_]]`。
- **表格**：表頭固定、淡斑馬紋、儲存格行高舒適；超寬表格會在自己的區塊內水平捲動，不會撐破版面。兩百多列的 Q&A 表格也能順暢閱讀。
- **程式碼**：highlight.js 語法上色、語言標籤、一鍵複製；行內程式碼有清楚的底色。
- **mermaid 圖表**：```` ```mermaid ```` 與 Azure DevOps Wiki 的 `::: mermaid` 寫法都支援，切換深淺色時會重畫。
- **提示區塊**：GitHub 風格的 `> [!NOTE]`、`[!TIP]`、`[!IMPORTANT]`、`[!WARNING]`、`[!CAUTION]` 各有顏色與標題。
- 其他：工作清單、刪除線、標題錨點（hover 顯示 #）、YAML front matter（摺疊成「文件資訊」表格）、`<kbd>`、換行視為 `<br>`（與 Azure DevOps 一致）。
- **repo 內的圖片**：相對路徑（`./images/x.png`、`/docs/x.png`）會透過 Git REST API 抓回來內嵌，與內建預覽一樣能顯示。
- 預覽內的連結與 HTML 模式相同：`#錨點` 跳轉、相對路徑在新分頁開啟 repo 內的檔案（`.md` / `.html` 會直接開在 Preview 頁籤）、外部網址開新分頁。

### 🔒 安全設計

- Markdown 內嵌的 HTML 會先經 DOMPurify 消毒（移除 `<script>`、`<style>`、`<iframe>` 等），再放進**沒有** `allow-same-origin` 的 sandbox 中渲染，與 HTML 預覽相同的隔離等級。
- 所有函式庫（marked、DOMPurify、highlight.js、mermaid）都打包在擴充功能內，不從 CDN 載入；mermaid 只在文件含圖時才載入。

### 🐛 修正

- **內嵌預覽後切換到其他檔案，Azure DevOps 顯示「An unexpected error has occurred within this region of the page」**：
  先前內嵌模式會把 Azure DevOps 的預覽區塊整個換成我們的 iframe，之後 Azure DevOps 要更新那個區塊時就會出錯。
  現在改為隱藏原本的預覽區塊、把 iframe 放在旁邊；切換檔案或分支時會自動移除內嵌預覽並恢復原本的區塊（HTML 與 Markdown 皆適用）。

### 🔄 行為變更

- HTML 檔的「完整預覽」行為不變。
- 內嵌預覽只對目前這個檔案有效：切換到其他檔案時會自動回到 Azure DevOps 內建預覽，需要再按一次按鈕。
- 預覽內的相對路徑連結若指向 `.md` 檔，新分頁會直接開在 Preview 頁籤（先前只有 `.html` 會）。
- 擴充功能體積變大（mermaid 約 3.5 MB），不影響一般頁面載入：mermaid 只在需要時讀取。

### ⚠️ 已知限制

- Markdown 預覽是「唯讀」的排版版本，不支援 Azure DevOps Wiki 專有的擴充語法（例如 `[[_TOSP_]]`、工作項目 `#123` 連結、`@提及`、影片嵌入）。
- CSS 內的 `url()`、Markdown 內用 HTML `<img>` 寫的相對路徑圖片會內嵌，但 `<video>`、`<audio>` 等不會。
- 與 v0.1.0 相同的限制請見 [v0.1.0 版本說明](https://github.com/doggy8088/ado-html-preview/releases/tag/v0.1.0)。
