## Azure DevOps HTML Preview v0.4.2 — 全面修正 HTML、Markdown、Excel / Office 與工作項目附件預覽的已知問題

### 🛠️ 修正

- **HTML 預覽：腳本字串內含 `<script>` 或 `</body>` 字樣時不再造成語法錯誤**：
  先前為預覽檔補上 CSP `nonce` 與注入輔助腳本時使用全文正規表示式取代，若網頁自身的 JavaScript 字串（例如動態組 HTML 的模板字串）、註解或屬性值裡出現 `"<script>..."` 或 `'</body>'`，會被誤插屬性或提早截斷而引發 `SyntaxError`，也受 `$&` / `$'` 等取代樣式字元影響。現在改依 HTML 標籤規則逐一掃描真正的標籤，略過 `<script>` / `<style>` / `<textarea>` 等純文字區段與註解，完整保留原始 doctype、排版與腳本內容，並對 `nonce` 屬性值補上跳脫。
- **就地換頁遇到載入失敗時，「← 上一頁」按鈕恢復正常**：
  - **內嵌模式**：換頁失敗的錯誤頁先前漏帶頁面 CSP `nonce`，導致左上角的「← 上一頁」腳本被擋下而無法顯示；現已補齊。
  - **全螢幕視窗**：popup 視窗沒有瀏覽器工具列，先前換頁失敗（例如目標檔不存在或來源分頁已關閉）時錯誤頁沒有返回鈕；現在錯誤頁同樣顯示「← 上一頁」圓鈕可退回上一份文件。
- **快速連續點擊連結或切換檔案不再競態錯亂**：
  - 就地換頁新增請求世代編號：先點載入較慢的連結、再改點另一個連結或按「← 上一頁」時，較早發出的舊請求完成後會自動作廢，不會倒蓋目前頁面。
  - 開啟檔案自動預覽時，若前一個檔案仍在下載中就切換到另一個檔案，會立即為新檔案觸發自動預覽（舊請求自動作廢），不再漏掉新檔案。
- **網址與路徑相容性、全螢幕暫存清理**：
  - 專案名稱含空白或中文時，預覽內開啟 repo 檔案連結會正確編碼。
  - 網址查詢參數 `path=` 未帶前導 `/`（如 `?path=docs/guide.md`）時，相對路徑圖片與連結也能正確解析所在目錄。
  - 全螢幕模式若開啟視窗失敗，會立即清除 `chrome.storage.session` 內的暫存內容，避免佔用 10 MB 配額。
- **工作項目預覽：同名附件不再顯示成同一份**：
  同一張工作項目若掛了多份同名的 `.html` 或 `.md` 附件，先前快取只以「工作項目 ID＋檔名」為鍵，在附件對話框用左右箭頭切換時會一直沿用第一份的預覽。現在遇到同名附件時會結合對話框當下顯示的原始碼指紋區分快取並監聽文字變更，左右切換同名附件能各自顯示正確的渲染結果。
- **Markdown 預覽：標題含行內標記不再中斷版面增強，並修正多項細節**：
  - 像 `# **主標 — 副標**` 或 `## [2.1 章節標題](url)` 這類含粗體、連結或行內程式碼的標題，不再因 DOM 節點層級假設拋出例外而中斷閱讀時間、清單卡片化、表格工具列與主題套用；各增強步驟與各表格彼此獨立容錯。
  - 側邊目錄與 `[[_TOC_]]` 改由語法樹提取標題純文字並解碼 HTML 實體（如 `&amp;`、`&copy;`），含 `>` 的屬性值或純圖片標題（如 `## ![A &amp; B](logo.png)`）都能正確產生目錄文字與錨點。
  - 行內三反引號程式碼（如 `` ```inline``` ``）不再被誤判為未關閉的程式碼圍籬，後續的 `[[_TOC_]]` 與 `::: mermaid` 圖表正常運作；直接寫在 Markdown 裡帶屬性的原始 `<table border="1">` 也會包上水平捲動容器。
  - 項目之間空一行的鬆散工作清單（Loose Task List）與緊密清單一致套用 Fluent 勾選框樣式；提示區塊（`> [!NOTE]` 等）內含標題時，捲動在頂端不再誤高亮該標題；修正表格拖曳欄位於按鈕外放開後的點擊狀態與非標準數字排序判斷，並補強 `<img name="...">` 與 `id="mermaid"` 的 DOM 屬性覆寫防護。
  - 微調淺色主題的次要說明文字、危險色與程式碼型別上色，全面符合 WCAG AA 4.5:1 對比標準。
- **Excel（`.xlsx`）預覽：工作表對應、索引色、空白凍結格與凍結窗格對齊修正**：
  - 移動或刪除過工作表的活頁簿，改依 `workbook.xml` 與 `workbook.xml.rels` 對回正確的工作表樣式與凍結窗格，並相容第三方匯出工具常見的 `xl/worksheets/...`、`/xl/worksheets/...`、`../worksheets/...` 等路徑寫法。
  - 修正 `indexed` 索引色因前導零遺失造成的色偏與 `indexed` 填色遺失問題，並支援活頁簿自訂的 `<indexedColors>` 色盤；沒有文字但設了底色或樣式的空白儲存格完整保留底色，凍結列／欄內的空白格在捲動時不再被下方文字穿過。
  - 修正寬文字擠壓列號欄造成的凍結欄錯位，並在載入、字型就緒、切換工作表與視窗縮放時依實際渲染尺寸動態校正凍結列／欄的 `sticky` 位移（含合併儲存格與非 A1 起始的工作表）；大表截斷提示列固定於上方不隨表格捲走。
- **Word（`.docx`）與 PowerPoint（`.pptx`）預覽細節修正**：
  - PowerPoint 補齊雙調整值預設幾何圖形（`round2SameRect` / `round2DiagRect` / `snip2SameRect` / `snipRoundRect`）的弧度與切角夾值，並改善無法顯示圖片佔位框對 `xlink:href` 與已卸載節點的處理。
  - 深色模式下 Word 與 PowerPoint 的錯誤提示改用高對比警示文字色，並在內容舞台區標示 `color-scheme: light` 維持紙張語意；Office 預覽文件的內嵌設定 JSON 統一跳脫 `<`。

### 🔁 行為變更

- **Markdown 一般文件維持一致欄寬**：移除先前對「無標題長文」自動縮窄至 760px 與放大行距／字距的分類規則，一般文件統一使用標準閱讀欄寬與字級；含 6 欄以上寬表的文件自動放寬至 1320px 的行為不變。
- **隱私權政策說明補齊**：更新 `docs/PRIVACY_POLICY.md`，明確說明 Excel、Word、PowerPoint 全螢幕模式與 HTML / Markdown 一樣僅透過 `chrome.storage.session` 短暫傳遞預覽文件（視窗讀取後立即刪除），並完整列出擴充功能內建的開源解析與渲染函式庫；所有處理皆在瀏覽器本機完成、零外部傳輸的原則不變。

### ⚠️ 已知限制

- 各檔案格式與工作項目附件預覽的既有格式限制與先前相同，請參閱 `release-notes/v0.3.3.md` 與 `release-notes/v0.4.0.md`。
