## Azure DevOps HTML Preview v0.2.12 — 新增 Word（.docx）預覽：高保真版面

### ✨ 新功能

- **Word 預覽 (內嵌)：在 Azure DevOps 檔案頁裡以高保真版面看 Word 文件**：
  打開 `.docx` 檔案時自動顯示（自動預覽與其他檔案類型一致），內嵌掛自製的「Preview」頁籤
  （Contents / History / Compare / Blame 可正常切換）。
- **Word 預覽 (全螢幕)**：開新視窗全螢幕預覽同一份文件。
- **高保真還原**：字型樣式、表格框線與底色、對齊、頁首頁尾、圖片、分頁與頁面尺寸皆依原稿
  （渲染引擎 docx-preview 0.4.1，Apache-2.0；壓縮處理 JSZip 3.10.1，MIT）。
- **配色採紙張語意**（與 Excel 預覽一致）：文件內容的顏色跟著「檔案」、不隨 App 深淺色主題改變；
  只有頂欄外殼跟隨主題（主題切換只影響外殼）。

### 🔒 安全設計

- **自帶渲染器**：docx-preview / JSZip 以原始碼字串打包（`docx-runtime.js`，由
  `scripts/build-docx-runtime.mjs` 產生），**只在 sandbox 預覽文件內執行**——
  父網頁與 userscript 都不載入這兩個函式庫，渲染不可信 docx 的程式與 Azure DevOps 頁面完全隔離。
- 文件內容以 base64 內嵌；圖片以 data URL 內嵌（`useBase64URL`），序列化後不會失效；
  `<script>` 內容一律跳脫 `</script`（防內容或函式庫意外關閉標籤）。

### 🔧 工程

- `make test` 新增 scripts/test-docx-core.mjs（輸入檔由 scripts/docx-fixture.py 手打最小 OOXML 產生）：
  payload base64 逐位元回還原、CSP nonce、注入安全、深／淺建置僅外殼不同（紙張語意的組裝層不變性）。
- Tampermonkey 版同步（`@version` 0.2.12）：docx-runtime / docx-core 內嵌，`@description` 一併補上
  Excel 與 Word（前一輪漏更）。

### ⚠️ 已知限制

- 僅支援 `.docx`（舊版 `.doc` 二進位格式不支援）。
- 追蹤修訂（tracked changes）以合併結果顯示；註解不顯示。
- 文件指定的字型未安裝時以系統近似字型呈現（與一般文件檢視器相同）。
- 超大文件（含大量圖片）的全螢幕模式受 10 MB 暫存上限限制；內嵌模式無此限。
