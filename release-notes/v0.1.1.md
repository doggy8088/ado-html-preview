## Azure DevOps HTML Preview v0.1.1 — 修正非預設分支的檔案預覽失敗

### 🐛 修正

- **網址沒有 `version=` 時預覽失敗（HTTP 404）**：
  直接點檔案樹或分享連結開啟檔案時，網址通常只有 `?path=…&_a=preview`，
  這時 Azure DevOps 顯示的是你**上次瀏覽的分支**（版本選擇器上看到的那個），不一定是 repo 的預設分支。
  先前擴充功能在這種情況下會去抓預設分支的檔案，若檔案只存在於其他分支，
  「完整預覽 (內嵌)」與「完整預覽 (全螢幕)」都會顯示「失敗：HTTP 404」。
  現在會改用版本選擇器上目前顯示的分支，預覽的內容與 Azure DevOps 畫面上看到的一致。
- 預覽內的相對路徑連結也會帶上同一個分支，在新分頁開啟時不會跳回預設分支。
- **非英文介面在 Contents 等頁籤按「完整預覽 (內嵌)」會失敗**：
  先前是用頁籤文字「Preview」找預覽頁籤，Azure DevOps 顯示語言設成中文等其他語言時，
  會出現「找不到 Preview 頁籤」。現在改用不隨語言變動的頁籤識別碼，任何顯示語言都能自動切到預覽頁籤。
- **Git LFS 追蹤的檔案預覽錯誤**：
  主 HTML 與內嵌的相對路徑資源（JS、CSS、圖片）若由 Git LFS 管理，先前抓到的是 LFS 指標檔
  （`version https://git-lfs.github.com/spec/v1 …`）而不是實際內容，導致畫面顯示指標文字或圖片破圖。
  現在會跟 Azure DevOps 一樣取得 LFS 的實際檔案內容；一般檔案不受影響。

### 🔄 行為變更

- 網址有 `version=GB…` / `GT…` / `GC…` 時行為不變，仍以網址為準。
- 若找不到版本選擇器（例如頁面尚未載入完成），會沿用舊行為抓預設分支。
