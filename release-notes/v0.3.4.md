## Azure DevOps HTML Preview v0.3.4 — 商店文案調整（修正審核退件）

> 這一版只調整說明文字，功能與 v0.3.3 完全相同。

### 🐛 修正

- **商店審核退件「關鍵字垃圾內容」（Yellow Argon）**：摘要原本一次列舉多種檔案格式名稱，
  被判定為過多／不相關的關鍵字。現在摘要只用一句話描述單一用途，格式細節留在詳細說明，
  並改以檔案副檔名（`.md` / `.pdf` / `.xlsx` / `.docx` / `.pptx`）描述各格式功能，
  不再列舉第三方產品名稱。

### 🔁 行為變更

- 僅擴充功能與商店的說明文字調整；按鈕、預覽行為與支援的檔案格式完全不變。

### ⚠️ 已知限制
