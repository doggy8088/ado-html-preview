## Azure DevOps HTML Preview v0.2.6 — 表格欄位可拖曳搬移，排序全面開放

### ✨ 新功能

- **拖曳搬移欄位順序**：直接拖曳表格的欄名（表頭）就能左右搬移整欄——水平位移超過
  4px 才進入搬移模式，純點擊仍然是排序，兩者互不干擾。拖曳過程中顯示插入位置標記，
  放下後表頭與所有資料格（含被篩選隱藏的列）隨欄移動，窄螢幕堆疊卡片的欄名標籤
  隨欄同行。
- **鍵盤搬移欄位**：在排序鈕上按 **Alt/Ctrl + ←／→** 即可左右搬移欄位。
- **無障礙播報**：拖曳或鍵盤搬移後以螢幕閱讀器可聽見的狀態播報
  「已將 X 欄移至第 n 欄」。
- **「還原順序與欄寬」連欄順一起還原**：還原鈕現在同時復原列順序、欄位順序、
  aria-sort 與所有欄寬。

### 🔄 行為變更

- **排序不再設 5 列門檻**：2 列以上的簡單表格皆可排序——此前 2–4 列的表格不會出現
  排序控制項，容易讓人以為沒有排序功能。
- 排序鈕的滑鼠提示加上搬移說明（「排序 · 拖曳以搬移欄位（Alt+←/→）」）。

### ⚠️ 已知限制

- 合併儲存格、多層表頭、多個 tbody 或巢狀表格不支援排序與欄位搬移（欄索引與視覺欄
  不對應，結構不安全）；這類表格仍有捲動與狀態徽章。
- 表頭含連結／按鈕的欄位不加排序鈕（避免巢狀互動元素），但仍可用滑鼠拖曳搬移，
  只是沒有鍵盤搬移的聚焦點。
- 觸控裝置上表頭保留縱向捲動（touch-action: pan-y），橫向拖曳仍可搬移欄位。
- 其餘限制與 v0.2.5 相同。
