## Azure DevOps HTML Preview v0.2.3 — 預覽內的連結就地換頁，像真的在逛網站

### ✨ 新功能

- **預覽內點擊連結不再開新分頁，直接在預覽中換頁**：
  HTML / Markdown 預覽裡指向 repo 文件的連結（`.html` / `.htm` / `.md` / `.markdown`，例如 `../docs/guide.md`）
  現在會在目前的預覽區塊就地換頁，多頁的網站或文件可以一頁頁逛下去，就像真的在瀏覽網站。
- **瀏覽器「上一頁 / 前進」逐頁可用**：每一份換頁都是一筆真的歷史紀錄，
  用工具列或鍵盤的上一頁會回到上一份文件（含捲動位置以外的頁面內容），前進亦然。
- **「← 上一頁」小圓鈕**：換過頁的文件左上角會出現一個低調的圓形按鈕，
  全螢幕（popup）視窗沒有工具列也能回上一頁；它與瀏覽器上一頁走同一條歷史，不會多堆一筆紀錄。
- **跨文件的錨點連結**（`guide.md#installation` 換頁後自動捲到目標段落。
- 內嵌、全螢幕、HTML、Markdown 四種組合都支援；Tampermonkey 版同步。

### 🔄 行為變更

- 一般點擊 repo 文件連結＝就地換頁；**Ctrl / ⌘ / Shift 點擊與中鍵點擊**仍開新分頁（開啟對應的 Azure DevOps 檔案頁），外部網址連結也維持開新分頁。
- 往前走了幾頁之後再點連結，會以新頁取代前進歷史（與瀏覽器行為一致）。
- 換頁失敗（檔案不存在、抓取失敗）時顯示錯誤頁（像瀏覽器的錯誤頁），上一頁仍可回到原本的文件。
- 預覽的載入機制由 `srcdoc` 改為 `blob:` URL 導覽（內容與渲染結果不變）：
  實測 `srcdoc` 反覆重設無法建立可用的歷史，上一頁只會重讀目前內容；改用 URL 導覽後上一頁才是真的回到上一份文件。
  全螢幕模式改用 `sandbox.html?nav=N` 導覽，機制相同。

### ⚠️ 已知限制

- 只有 `.html` / `.htm` / `.md` / `.markdown` 會就地換頁；其他相對路徑（`.png`、`.pdf`…）仍開新分頁到 Azure DevOps 的檔案頁。
- 帶 query 的連結（`page.html?id=3`）只會換頁到該文件，query 不會傳遞（repo 內的檔案路徑不含 query）。
- 全螢幕模式的換頁與按需圖片一樣，需要原本的 Azure DevOps 分頁還開著（由它代為抓檔）。
- Tampermonkey 全螢幕是 popup 視窗、沒有工具列：回上一頁請用文件左上角的「←」鈕或鍵盤快捷鍵。
- 其餘限制與 v0.2.2 相同。
