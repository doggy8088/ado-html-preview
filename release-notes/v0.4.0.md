## Azure DevOps HTML Preview v0.4.0 — 工作項目附件直接預覽

### ✨ 新功能

- **工作項目的 HTML / Markdown 附件直接顯示渲染結果**：在 Boards 的工作項目點開 `.html` / `.htm` 或 `.md` / `.markdown` 附件時，
  Azure DevOps 內建的附件預覽對話框原本只顯示原始碼；現在對話框會直接顯示渲染後的內容，不必按任何按鈕。
  - HTML 附件以啟用 JavaScript 的 sandbox 顯示完整網頁（與 repo 檔的「完整預覽」相同的隔離方式）。
  - Markdown 附件使用與 repo 檔相同的 Markdown 預覽主題：深淺色、側邊目錄、程式碼上色與複製、mermaid 圖表。
  - 預覽區撐滿對話框左右箭頭之間的空間，比原本的原始碼檢視更大。
- **標題列的「原始碼」切換鈕**：隨時切回 Azure DevOps 原本的原始碼檢視，再按一次（「完整預覽」／「Markdown 預覽」）回到渲染結果。
- 對話框的左右箭頭切換附件時，預覽自動跟著換；焦點在預覽內時按 Esc 一樣會關閉對話框。

### 🔁 行為變更

- 擴充功能現在也會在工作項目頁面讀取「你在對話框中打開的那一份附件」（透過 Work Item Tracking REST API，使用你現有的登入狀態）。
  隱私權政策已同步更新；不收集、不傳送任何資料的原則不變。
- Repos 檔案頁的預覽行為完全不變。

### ⚠️ 已知限制

- 附件不在 repo 裡、沒有目錄：HTML / Markdown 內以相對路徑引用的圖片、腳本、樣式表與文件連結無法解析；外部網址與 CDN 資源不受影響。
- 只支援已儲存的附件（剛加入、尚未儲存工作項目的附件仍顯示原始碼）。
- 目前只處理 HTML 與 Markdown 附件；PDF、Office 文件等其他格式維持 Azure DevOps 原本的行為。
- 沒有全螢幕模式；需要更大的畫面時可下載附件或把檔案放進 repo。
