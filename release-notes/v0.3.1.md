## Azure DevOps HTML Preview v0.3.1 — 修正商店打包清單（防漏包自我檢查）

### 🐛 修正

- **Chrome Web Store 上架包（zip）漏檔**：`scripts/package.sh` 的檔案清單是寫死的舊清單，
  漏掉 manifest 已引用的 `xlsx-core.js`、`docx-core.js`、`docx-runtime.js`、`vendor/xlsx.full.min.js`。
  這種殘缺包送商店必被拒（擴充功能載入也會失敗）。已補齊清單。
- **`package.sh` 新增自我檢查**：打包後逐一確認「manifest 引用到的檔案」全數在 zip 內，
  缺漏直接失敗——這類「manifest 引用但漏包」的問題以後出不了廠。

### ℹ️ 商店上傳狀態說明

- v0.3.0 的 GitHub Release 已建立且內容完整；其 Chrome Web Store 上傳**在送出前就被擋下**
  （`FAILED_PRECONDITION`：商店目前有版本正在審查中，審查期間不收新上傳），
  所以**沒有殘缺包流入商店**。
- 等商店審查完成後，手動執行 publish workflow 並勾選 `cws_upload` 即可上傳本版：
  `gh workflow run publish.yml -f cws_upload=true`（或 Actions 頁面手動執行並勾選）。

### 其他

- 內容與 v0.3.0 相同（Excel / Word 預覽、紙張語意、視覺驗證框架），本版僅修復上架打包。
