## Azure DevOps HTML Preview v0.2.10（未單獨發布，併入 v0.2.11 一起發布）— 新增 Excel（.xlsx）預覽：主題化的唯讀表格

### ✨ 新功能

- **Excel 預覽 (內嵌)：在 Azure DevOps 檔案頁裡直接看試算表**：
  打開 `.xlsx` 檔案時自動以**自家主題的唯讀表格**顯示（自動預覽與 HTML / Markdown / PDF 一致）。
  內嵌預覽與 PDF 一樣掛在自製的「Preview」頁籤：Contents / History / Compare / Blame 可正常切換。
- **Excel 預覽 (全螢幕)**：開新視窗全螢幕預覽同一份唯讀表格（走既有 sandbox 頁管線）。
- **唯讀表格的還原度**：
  - 多工作表以頁籤切換（含無障礙角色）；頂欄顯示檔案名、工作表數與儲存格統計。
  - 儲存格**基本樣式**：粗體、斜體、底線、刪除線、字色、底色、對齊（水平／垂直）、自動換行、字級。
  - **數字格式**：日期、百分比、千分位、自訂格式（顯示 Excel 的格式化文字）。
  - **合併儲存格**、**欄寬**、**列高**（pt→px 換算）、**凍結窗格**（依檔案設定，捲動時固定）。
  - 佈景主題色（theme 色 + tint）以檔案內建色盤還原，讀不到時用 Office 預設色盤近似。
  - 附 Excel 風格的**欄字母（A、B、C…）與列號標頭**，長表格好定位。
- 以 Git Items REST API 的二進位格式（`$format=octetStream&resolveLfs=true`）取回原始檔，**支援 Git LFS**。
- 解析用 **SheetJS Community Edition（Apache-2.0，vendor 進 repo）**；Tampermonkey 版同步（`@version` 0.2.10，
  SheetJS 與 xlsx-core.js 一併內嵌）。

### 🔧行為變更

- `.xlsx` 檔案頁的頁籤列右側會出現「Excel 預覽 (內嵌)」與「Excel 預覽 (全螢幕)」兩顆按鈕並自動顯示預覽。
- 自製「Preview」頁籤機制自 PDF 擴充為 **PDF / xlsx 共用**（內部命名同步改為 docTab）。
- 樣式還原的小知識：SheetJS 社區版只把填色放進 `cell.s`，其餘樣式（字型／對齊）在 `wb.Styles` 但不帶每格的
  樣式索引——本擴充功能直接掃描 xlsx（ZIP）內的工作表 XML 取回每格的 xf 索引再還原完整樣式。

### ⚠️ 已知限制

- 僅支援 `.xlsx`（`.xls` / `.xlsm` / `.xlsb` 未支援）。
- 不支援圖片、圖表、樞紐分析、篩選與公式編輯（公式顯示快取值）；富文字多段格式取顯示文字。
- 單一工作表超過 60,000 格（或 5,000 列）會截斷顯示並出現提示；超大檔案的全螢幕模式受 10 MB 暫存上限限制。
- 樣式索引以工作表 XML 編號（sheetN）對應工作表順序，極端情況（編號與順序不一致的檔案）樣式可能對錯表。
- 凍結窗格以檔案的 pane 設定還原；沒有設定時固定欄字母與列號標頭。
